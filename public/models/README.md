# Face Landmarker model

`face_landmarker.task` is Google's MediaPipe Face Landmarker float16 model
bundle, downloaded from the official `latest` model URL on 2026-07-29:

https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task

The server hosts the model locally so the installation does not depend on an
internet connection while running.
